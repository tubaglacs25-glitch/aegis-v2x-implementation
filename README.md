# AEGIS·V2X

**Track:** Open Innovation
## Problem Statement Alignment
**The Core Problem:** Indian roads lack real-time, data-driven V2X (Vehicle-to-Everything) emergency ecosystems, causing delayed medical responses.
**Our Technical Solution:** AEGIS-V2X bridges this gap by deploying an automated SOS routing system with accessible, localized UI components to minimize emergency response times.

## System Efficiency & Code Quality
- **Performance:** Implemented optimized rendering and dynamic imports to ensure high Lighthouse scores.
- **Security:** Strict data validation and secure API routing.
- **Accessibility (a11y):** Fully compliant with ARIA standards, screen-reader ready, and bilingual support.
- **Testing Coverage:** Automated unit testing configured via Jest for core modules.
