# Hackathon demo walkthrough

**Opening:** “AEGIS·V2X brings historical road-safety reporting and a connected response workflow into one interface. Official report figures and simulated operations are clearly separated.”

1. **Overview:** show 2024 national totals and the five-year report trend. Clarify that these are annual aggregates, not live feeds.
2. **Risk context:** show state fatality ranking. Explain the map is illustrative and contains no crash coordinates.
3. **Driver:** open the route section and show the labelled demo location. Optionally grant device location. Explain route geometry and route risk are not implemented.
4. **SOS:** start the simulated countdown, point out the cancellation action, then let it expire. State clearly that no emergency service is contacted.
5. **Authority:** show incident AG-24-118 appearing in the same page session.
6. **Hospitals:** run the Overpass discovery and explain results are public map records, not verified emergency intake or capacity. Note the need for internet access.
7. **Analytics:** show the selected-city and state tables and call out the report coverage/aggregate limitations.

**Close:** “The prototype demonstrates a transparent workflow. Live sensors, verified dispatch, durable shared incidents, routing, and emergency-grade validation are future engineering work, not capabilities being claimed today.”
